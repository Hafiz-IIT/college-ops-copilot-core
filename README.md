# College Ops Copilot Core

A transparent workflow core for routing student administrative requests to the right office with the right evidence.

## Implemented
- request categories and office routing
- required-document checks
- priority/SLA hints
- missing-information response
- ticket state and audit events
- deterministic tests

## Scope
This is an administrative operations prototype, not a deployed college ERP, admissions engine, or student-record system.
